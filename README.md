# AIByte Backend API

Production-grade backend for **AIByte**, an Expo micro-learning platform focused on AI learning, video lessons, quizzes, progress tracking, streaks, notifications, and scalable retention systems.

Built with:

- Node.js
- Express.js
- TypeScript
- PostgreSQL
- Prisma ORM
- Clerk Authentication
- Redis
- Neon DB
- Zod Validation
- Sentry
- Arcjet
- Rate Limiting

---

# Features

## Authentication

- Clerk JWT verification
- Secure protected routes
- Session persistence
- User sync with PostgreSQL
- Secure logout support

## Learning System

- Courses API
- Lessons API
- Resume learning
- Progress tracking
- Video lesson support

## Quiz Engine

- Quiz submission
- Quiz attempts tracking
- Score history

## User Profile

- Profile management
- Preferences system
- Avatar support
- Public user profile
- Account deletion

## Retention Systems

- Daily streak engine
- XP rewards
- Achievement system
- Bookmarks
- Resume learning API
- Recommendations API

## Notifications

- Device token registration
- Push notification preferences
- Notification inbox
- Deep linking support

## Admin CMS

- Create courses
- Create lessons
- Create quizzes
- Update/Delete content
- Scalable content operations

## Production Hardening

- Zod validation
- Centralized error handling
- Structured logging
- Request tracing
- Rate limiting
